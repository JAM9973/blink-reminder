# 제안서 도식 설명과 문제 상황 근거

## 링크 신뢰성 검토

- 제공한 글 [순천향대학교 부속 부천병원, 「컴퓨터와 눈건강」](https://www.schmc.ac.kr/bucheon/selectBbsNttView.do?key=1006&bbsNo=203&nttNo=144594)은 대학병원 공식 홈페이지의 건강정보다. **컴퓨터 사용 중 눈 깜빡임이 줄고 눈의 건조감이 생길 수 있다**는 문제 상황을 소개하는 용도로 적절하다.
- 다만 페이지에서 작성자·작성일·인용 연구를 확인하기 어렵고, 본문에 **2005년 통계**가 나온다. ‘사무직 80%’, ‘정상 분당 10~15회’, ‘최대 60% 감소’ 같은 수치를 현재의 일반적인 사실이나 프로그램 알림 기준으로 옮기지 않는다.
- 더 최근의 보강 자료로 미국 국립안연구소(NEI)의 [Dry Eye](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/dry-eye)를 사용할 수 있다. 이 기관은 화면을 오래 보는 일이 안구건조와 관련될 수 있고, 화면을 보다가 쉬는 것을 권고한다고 안내한다. 해당 페이지의 갱신일은 2025년 8월 6일이다.
- [2023년 눈 깜빡임 관찰 연구](https://pubmed.ncbi.nlm.nih.gov/36763349/)에서는 인쇄물과 디지털 기기로 읽을 때 모두 대화할 때보다 깜빡임이 적었다. 따라서 감소 원인을 **화면 자체만의 문제**로 단정하지 않고, 화면을 보며 집중하는 사용 상황에 초점을 맞춘다.
- **프로그램 효과는 별도의 검증 대상이다.** 위 자료는 문제 상황을 뒷받침하지만, 이 프로그램이 안구건조를 예방하거나 치료한다는 증거는 아니다. 설정 기준도 의학적 정상치가 아니라 사용자가 정하는 알림 조건이다.

### 2번 슬라이드에 넣기 좋은 문장

> 화면에 집중하면 눈 깜빡임이 줄고 눈이 건조해질 수 있습니다. 그래서 노트북 사용을 방해하지 않으면서 깜빡임을 알려주는 기능을 제안합니다.

슬라이드 아래쪽 출처 표기 예시: **순천향대학교 부속 부천병원, 「컴퓨터와 눈건강」; 미국 국립안연구소, 「Dry Eye」(2025).** 발표 대본에서는 ‘눈이 건조해질 수 있다’까지 말하고 의료 효과를 단정하지 않는다.

## 도식 파일과 쉬운 설명

### 01 프로그램 구조도

- 파일: `01_프로그램_구조도.png` / `01_프로그램_구조도.svg`
- PPT 위치: **5번 슬라이드, 구현 구조**.
- 약 20초 설명: “웹캠이 눈을 비추면 Python과 MediaPipe가 눈 위치를 찾습니다. 찾은 정보를 C 코드에 전달하면 C가 깜빡임 횟수와 최근 60초 기록을 계산합니다. 사용자가 정한 기준보다 낮은 상태가 계속되면 반투명한 눈 아이콘을 잠시 보여줍니다.”
- 기억할 핵심: **Python은 눈 위치 찾기, C는 횟수·알림 판단**.

### 02 UI 와이어프레임

- 파일: `02_UI_와이어프레임.png` / `02_UI_와이어프레임.svg`
- PPT 위치: **4번 슬라이드, UI·접근성 설계**.
- 약 20초 설명: “평소에는 카메라 창을 띄우지 않고 작업 표시줄에서 상태를 확인합니다. 기준에 못 미치면 반투명한 눈 아이콘이 잠시 나타납니다. 설정창에서 아이콘 크기와 투명도를 바꾸고, 필요하면 글자 안내를 켤 수 있게 설계하겠습니다.”
- 화면에 보이는 숫자는 **설명용 예시값**이며 의학적 기준이 아니다. 이 그림은 실제 실행 화면이 아니라 설계안이다.

### 03 개발 일정

- 파일: `03_개발_일정.png` / `03_개발_일정.svg`
- PPT 위치: **7번 슬라이드, 개발 환경·일정**.
- 약 15초 설명: “이번 5주차에는 제안서를 제출하고, 이후 감지와 C 판정, 백그라운드 UI, 접근성 개선을 순서대로 진행합니다. 마지막에는 사람이 직접 센 횟수와 비교해 오차를 확인하고 최종 발표를 준비하겠습니다.”
- ‘13주차 전후’는 **남은 약 8주를 기준으로 한 예상**이다. 실제 최종 마감 주차에 맞춰 바꾼다.

## PPT에 넣는 방법

PNG와 SVG 모두 16:9 비율이다. PowerPoint에는 PNG를 삽입하면 화면이 가장 일관되게 보인다. SVG는 크기를 자유롭게 조절하기 좋다. `도식_생성.py`를 다시 실행하면 두 형식의 파일을 재생성할 수 있다.
